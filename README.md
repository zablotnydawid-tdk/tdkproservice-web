# TDK&ProService

Pełny projekt wizytówki online dla TDK&ProService:
- Frontend: Vite + React
- Backend: Express (API kontaktowe)
- Styl prosty i nowoczesny, responsywny

## Development

1. zainstaluj zależności:
   ```
   npm install
   ```
2. uruchom tryb deweloperski:
   ```
   npm run dev
   ```
   - *Vite* serwuje frontend na `http://localhost:5173`
   - *Express* serwuje backend na `http://localhost:3000`

## Build & Production

1. zbuduj frontend:
   ```
   npm run build
   ```
2. uruchom serwer:
   ```
   npm start
   ```
   frontend i API będą dostępne na `http://localhost:3000`
